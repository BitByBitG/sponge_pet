海绵桌面宠物 v7（Windows 10/11）

先退出旧版，解压后双击 start.bat。
需要 Windows 版 Python 3（含 Tcl/Tk），无需安装 pip 依赖。
保留 assets 文件夹和 pet.ini；不要在 WSL 中运行。

左键点击：切换自由走动 / 跟随鼠标。拖动：移动位置。
右键海绵：直接喂蟹黄堡，不需要开启权限。
走动、跟随或暂停时都可以喂食；吃东西时再次右键从第一帧重新播放。
吃蟹黄堡顺序：1 2 3 4 5 6 2 3 4 5 6。
吃完后恢复原来的移动或暂停状态。

点击右下角托盘海绵图标打开设置。
设置保留大小、透明度、置顶、暂停、隐藏/显示和退出，以及喂食按钮。
大小 50%~200%；透明度 0%~100%（0% 为完全不透明）。
完全透明后仍可从托盘恢复，设置窗口不透明。

动画和速度统一在程序旁边的 pet.ini 修改，重启后生效：
[animation]
walk_fps = 5
eat_fps = 3
[movement]
walk_speed = 65
follow_speed = 220

walk_fps / eat_fps：每秒播放的动画帧数，支持小数，不是素材数量。
walk_speed / follow_speed：屏幕像素/秒，支持小数。
四项都必须是大于零的有限数值，缺项或错误值使用默认值。
默认吃蟹黄堡 11 帧，以 3 帧/秒播放，总时长约 3.67 秒。
设置窗口已移除动画帧率、移动速度和允许喂食开关。
原来 JSON 里保存的速度不再生效。
大小、透明度、置顶仍保存到 %LOCALAPPDATA%\SpongePet\settings.json。

活动范围为主显示器工作区。
已通过语法、11 帧顺序、动画时长、暂停状态喂食、重复喂食及 INI 检查。
